# AI Tutor

An AI-powered programming tutor developed for the **Summer Scholars Program (SSP)** to provide guided, interactive assistance while students work on programming labs.

## Overview

The AI Tutor is designed to help students learn programming concepts without simply providing complete solutions. Instead, it acts like a teaching assistant by guiding students through the problem-solving process.

The tutor automatically receives the student's current code workspace, enabling it to provide context-aware assistance throughout each lab.

## Features

- Interactive conversational interface
- Context-aware assistance based on the student's current code
- Guided learning through questions and hints
- Help with debugging and error diagnosis
- Explanations of programming concepts
- Browser-based interface with no installation required

## Access the AI Tutor

The AI Tutor is available online at:

**https://ai-tutor-ssp-web.vercel.app/**

## Intended Audience

The tutor supports both learning tracks in the Summer Scholars Program:

- High School (HS)
- CSUF Undergraduate (UG)

The tutoring experience is tailored to the selected learning track.

## Educational Philosophy

The AI Tutor is designed to encourage students to think through problems independently. Rather than supplying finished answers, it provides guidance, hints, and explanations that help students develop a deeper understanding of programming concepts and improve their problem-solving skills.
